# 🇦🇲 Барев, цитик! Добро пожаловать на застолье в игре «От лаваша до кочари»!

Маленькая пиксельная игра про большое армянское застолье. Нажимай на лаваш, собирай еду и готовься танцевать!

## Запуск

Нужен Go 1.22 или новее. Из корня проекта **с кайфом** выполни:

```sh
go run .
```

Открой http://localhost:8080

## Как играть

Нажимай на еду мышью

| Клики | На столе |
| --- | --- |
| 0–5 | Лаваш |
| 6–15 | Добавляется шашлык |
| 16–30 | Добавляются помидор, зелень и лук |
| 31–49 | Появляется вино |
| 50 | А теперь танцуем кочари! |

На 50-м клике счётчик останавливается, а стол танцует. Кнопка «Ещё одно застолье» начинает игру заново.
